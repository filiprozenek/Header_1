# 🌐 _Header_
This repository contains the code (_HTML_ & _CSS_) for a basic [_Header_](https://codebyfr-header-1.infinityfreeapp.com/).

### 🖥️ Desktops / Tablets
For desktop & tablet devices, the _Header_ is pretty simple, of course, it has some basic features like _hover effect_ on Icons etc., but it is more interesting when it comes to the mobile devices display.
